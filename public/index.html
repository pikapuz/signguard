What the guard checks

      
    
        
  • Unlimited allowance — approve() for type(uint256).max is the classic drain setup.
    • 
        
  • Approval for all — setApprovalForAll(true) hands over a whole NFT collection.
    • 
        
  • Permit abuse — permits with max value or deadlines years away.
    • 
        
  • Hidden approvals — dangerous calls bundled inside multicall().
    • 
        
  • Unknown functions — calldata the guard cannot decode is flagged, never trusted.
    • 
        
  • Target type — EOA vs contract, via eth_getCode.
    • 
        
  • Upgradeable proxies — EIP-1967 implementation and beacon slots.
    • 
        
  • Contract age — contracts that did not exist ~30 days ago.
    • 
      

      
Scoring is deterministic: every transaction starts at 100. A critical finding costs 60 points, a warning 15. Any critical finding blocks. SAFE is 80+, CAUTION 50–79, BLOCK below 50. The guard only performs read-only RPC calls — it never asks for a wallet connection and never signs anything.
